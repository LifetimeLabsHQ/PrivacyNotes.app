## Default Permission

Text in pictures (Apple Vision), Scan a page (VisionKit, iOS) and Voice to text (SpeechAnalyzer), with Cancel for a transcription.

#### This default permission set includes the following:

- `allow-ocr`
- `allow-scan`
- `allow-speech-status`
- `allow-speech-install`
- `allow-transcribe`
- `allow-cancel`

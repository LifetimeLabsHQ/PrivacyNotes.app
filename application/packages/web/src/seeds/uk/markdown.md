Усе, що нижче, зроблено за допомогою панелі вгорі цієї нотатки. Жодних налаштувань, жодних плагінів. Виділіть текст, і панель діятиме на нього. Клацніть у порожньому рядку, і вона почне щось нове.

## Слова

Слово можна зробити **жирним**, *курсивом* або ***і тим, і тим***. Його можна перекреслити, ось ~~так~~. Його можна <u>підкреслити</u>. Дрібне пишуть <sub>нижнім індексом</sub>, а степені <sup>верхнім індексом</sup>.

Текст може бути <span style="color: #e03131">червоним</span>, <span style="color: #1971c2">синім</span>, <span style="color: #2f9e44">зеленим</span> або будь-яким із дев’яти кольорів.

Його можна ==виділити жовтим== або <mark style="background-color: rgba(64, 192, 87, 0.35)">зеленим</mark>.

Спойлер ховає слова, доки хтось не клацне їх: подарунок ||програвач платівок||. Виділіть слова й виберіть **Спойлер** у меню **Вставити** або введіть дві вертикальні риски з кожного боку.

Значок або логотип може стояти в рядку тексту, як-от :icon[gift] :icon[coffee] :icon[rocket-launch] або :logo[github]. Виберіть його в **Вставити** > **Значки й логотипи**.

Кнопка **Aa** змінює розмір і шрифт. Текст може бути <span style="font-size: 0.85em">дрібним</span>, звичайним або <span style="font-size: 1.6em">великим</span>. Він може бути <span style="font-family: ui-sans-serif, system-ui, sans-serif">простим</span>, <span style="font-family: ui-serif, Georgia, Cambria, serif">із засічками</span> або <span style="font-family: ui-monospace, SFMono-Regular, Menlo, monospace">моноширинним</span>.

## Де стоять слова

<p style="text-align: center;">Цей абзац вирівняно по центру.</p>

<p style="text-align: right;">А цей зсунуто праворуч.</p>

Вирівнювання переміщує весь абзац, ніколи не окреме слово. Поставте курсор в абзац і скористайтеся кнопкою вирівнювання.

## Виноски

Виноска є кольоровим блоком для того, що читач не повинен пропустити. Введіть `[!` у порожньому рядку, щоб вибрати її.

> [!tip]+ Порада
> Клацніть її значок, щоб згорнути.

> [!warning]+ Попередження
> Кожен вид має свій колір і свій значок.

> [!danger]+ Небезпека
> Видів багато. Меню **Вставити** показує їх усі.

> [!fold]- Згортуваний блок
> Без рамки й кольору: просто текст, що не заважає, доки ви його не відкриєте.

## Виноски

Виноска виносить джерело чи примітку за межі тексту.[^1] Введіть `[^1]` після слова або виберіть **Виноска** в меню **Вставити**. Натисніть маленьке число, щоб перейти до виноски.

## Код

Код зберігає свої відступи й розфарбовується відповідно до мови. Назва вгорі блоку показує його мову: натисніть її, щоб вибрати іншу.

```js
export function seal(note, key) {
  const nonce = randomBytes(24);
  return xchacha20poly1305(key, nonce).encrypt(note);
}
```

```python
def rolling_mean(values, window):
    return [sum(values[i:i + window]) / window
            for i in range(len(values) - window + 1)]
```

Довгий блок відкривається згорнутим, щоб решта нотатки була поруч. Кнопка під ним показує всі рядки.

```js
const WORDS_PER_MINUTE = 200;

export function readingStats(markdown) {
  const text = markdown
    .replace(/!\[[^\]]*\]\([^)]*\)/g, ' ')
    .replace(/\[([^\]]*)\]\([^)]*\)/g, '$1')
    .replace(/[#*_~`>|-]/g, ' ');

  const words = text.split(/\s+/).filter(Boolean);
  const headings = markdown.match(/^#{1,6} /gm) ?? [];
  const tasks = markdown.match(/^\s*- \[[ x]\] /gm) ?? [];
  const done = tasks.filter((task) => task.includes('[x]'));

  return {
    words: words.length,
    minutes: Math.max(1, Math.round(words.length / WORDS_PER_MINUTE)),
    headings: headings.length,
    tasks: tasks.length,
    done: done.length,
  };
}

export function summary(stats) {
  const parts = [`${stats.words} words`, `${stats.minutes} min read`];
  if (stats.headings > 0) {
    parts.push(`${stats.headings} sections`);
  }
  if (stats.tasks > 0) {
    parts.push(`${stats.done} of ${stats.tasks} tasks done`);
  }
  return parts.join(' · ');
}

export function isLongRead(stats) {
  return stats.minutes >= 10;
}
```

Блок коду може мати заголовок. Клацніть назву мови й виберіть **Додати заголовок**. Стрілка біля заголовка згортає блок до одного рядка, і нотатка це запам’ятовує.

```bash title="backup.sh" fold
#!/bin/sh
# Copy the notes folder into a dated archive.
tar -czf "notes-$(date +%F).tar.gz" "$HOME/Notes"
```

**Блок для копіювання** містить одну річ, яку треба скопіювати, як-от адресу чи команду. Його кнопка копіює все одним клацанням.

```copy
ssh-keygen -t ed25519 -C "laptop"
```

Короткий шматок коду всередині речення виглядає `ось так`. Утримуйте Cmd (Ctrl у Windows і Linux) і клацніть його, щоб скопіювати.

## Посилання

Їх два види, і вони навмисно виглядають по-різному.

- Вебпосилання відкриває сайт: [privacynotes.app](https://privacynotes.app/uk)
- Вебпосилання може мати текст підказки. Наведіть вказівник на [це посилання](https://privacynotes.app/uk/help "Наші сторінки довідки") і зачекайте.
- Посилання на нотатку відкриває іншу вашу нотатку: [[Як захищено ваші нотатки]]

Для обох є кнопка на панелі. Ланцюжок створює вебпосилання. Дужки створюють посилання на нотатку: вони показують ваші нотатки, і ви вибираєте потрібну. Введення `[[` робить те саме.

Посилання на нотатку не мусить виглядати як назва нотатки. Введіть назву, риску, а потім слова, які хочете бачити на сторінці: [[Як захищено ваші нотатки|ці слова]] відкривають ту нотатку.

Посилання на нотатку може також відкрити її на одному із заголовків. Введіть `#` після назви й виберіть заголовок: [[Як захищено ваші нотатки#Хто тримає ваш ключ]] відкриває ту нотатку на розділі про ключ. Значок посилання біля заголовка у структурі скопіює таке посилання за вас.
